# Changelog

## 1.0.0 — 2026-10-24

First public version of LaunchNotes:

- Browser app organizes conventional and plain commit subjects into readable sections.
- Live Markdown preview, release announcement draft, copy buttons, and Markdown download.
- Suggested semantic version increments with an editable version field.
- Dependency-free Node CLI for generating release Markdown from a text file.
- Local static server and cross-platform GitHub syntax-check workflow.
