# Contributing

Thanks for considering a contribution. Useful ideas include support for additional commit conventions, careful duplicate handling, keyboard accessibility, and better platform instructions.

- Use fictional example messages only. Never commit customer names, internal ticket IDs, proprietary release text, or credentials.
- Keep the runtime dependency-free unless the need is clear and the security implications are reviewed.
- Preserve original commit wording; suggestions must remain reviewable.
- Explain behavior and tradeoffs in a focused pull request.
- Run `npm run check` before submitting.
- Never add automatic publishing, telemetry, or remote commit scanning without an explicit opt-in and clear security review.

Contributions are made under the repository's MIT license.
